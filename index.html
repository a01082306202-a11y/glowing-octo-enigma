1. 연결하기

회원가입 없이 두 기기를 직접 연결하는 시험용 버전이야. 한 명이 '방 만들기', 다른 한 명이 '초대 코드 붙여넣기'를 해. 연결 코드는 길 수 있어.
① 아래 초대 코드를 친구에게 보내 줘.
② 친구가 만든 응답 코드를 아래에 붙여넣고 연결하기.
① 방 만든 친구에게 받은 초대 코드를 붙여넣어.
② 아래 응답 코드를 방 만든 친구에게 보내 줘.
아직 연결되지 않았어.

알아둘 점

• 이 버전은 중앙 서버 대신 WebRTC로 두 기기를 직접 연결하는 실험용이야.
• 초대/응답 코드를 한 번 주고받아야 하고, 연결이 끊기거나 한쪽이 페이지를 닫으면 다시 연결해야 할 수 있어.
• 두 기기가 서로 다른 네트워크에 있으면 연결이 실패할 수도 있어. 이 경우 안정적인 서버 호스팅이 필요해.
• 글은 현재 연결된 동안 상대에게 실시간 전송돼. 서버에 영구 저장되는 서비스는 아니야.
• 초대 코드는 비밀번호처럼 취급하고 다른 사람에게 공개하지 마.
